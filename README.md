# 宿舍查寝管理系统

一个免安装、免服务器的本地网页应用，用于学校 / 宿管场景的晚间查寝管理。双击 `index.html` 即可在浏览器中使用。

## 功能一览

| 模块 | 说明 |
|------|------|
| 📊 仪表盘 | 今晚查寝进度、在寝率、异常名单（未归/晚归）、近 7 天异常趋势、进行中的请假 |
| ✅ 查寝打卡 | 按楼栋/宿舍逐人标记 **在寝 / 晚归 / 未归 / 请假**，支持备注、全寝在寝一键标记、补录历史日期、仅看未查、导出当日 CSV |
| 📝 请假管理 | 登记请假（病假/事假/外出等），自动为请假期间未查寝的日期标记「请假」 |
| 👥 学生管理 | 增删改查、批量导入（文本粘贴）、按班级/宿舍筛选、导出 CSV |
| 🏠 宿舍管理 | 楼栋/楼层/房号/容量/性别管理，入住率与成员一览 |
| 📈 统计报表 | 按日期区间统计晚归、未归、请假次数，班级汇总与学生明细，导出 CSV |
| ⚙️ 数据管理 | JSON 备份导出/恢复、加载演示数据、清空数据 |

## 快速上手

1. 双击 `index.html` 用浏览器打开（推荐 Chrome / Edge）。
2. 首次打开会自动加载**演示数据**，可直接体验各功能。
3. 正式使用前，进入「数据管理 → 清空数据」，然后：
   - 先在「宿舍管理」添加楼栋和房间；
   - 再到「学生管理」逐个添加或**批量导入**学生
     （格式：`姓名,学号,性别,班级,楼栋,房号,床号,电话`，床号留空自动分配，楼栋不存在会自动创建）。
4. 每晚查寝：进入「查寝打卡」，选当天日期，逐人点状态按钮即可；点「全寝在寝」可快速完成正常宿舍。

## 数据存在哪里？

所有数据保存在**本机浏览器**的 localStorage 中（不上传任何服务器）：

- 换浏览器、换电脑或清理浏览器数据会导致数据丢失；
- 请定期在「数据管理 → 导出备份文件」保存 JSON 备份，需要时通过「数据恢复」导入。

## 常见问题

- **误点了状态？** 再点一次同一按钮即可取消标记。
- **昨晚忘了查？** 「查寝打卡」里把日期改回昨天补录即可。
- **导出的 CSV 用 Excel 打开乱码？** 文件已带 BOM，一般可直接打开；若仍乱码，用 Excel 的「数据 → 从文本/CSV」导入并选择 UTF-8。
